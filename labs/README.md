## Progression by day

**Day 1 — Copilot Foundations, Word and PowerPoint** · Topic 01: Copilot Foundations and Content Creation in Word and PowerPoint  
Labs 01–05: Set Up Microsoft 365 Copilot and Prompt Safely; Draft a Project Brief in Word from Excel Evidence; Refine a Responsible Copilot Use Policy in Word; Build a PowerPoint Story from Word and Excel; Enhance PowerPoint with Native Charts and Speaker Notes

**Day 2 — Copilot for Excel and Outlook** · Topic 02: Copilot for Excel and Outlook: Analysis and Communication  
Labs 06–10: Build and Audit Excel Formulas with Copilot; Run Deep Descriptive and Diagnostic Analysis in Excel; Forecast and Stress-Test a Campaign with Copilot; Triage an Outlook Inbox and Draft a Controlled Reply; Turn Meeting Notes into an Action Register

**Day 3 — Business Process Automation with Power Automate** · Topic 03: Business Process Automation with Power Automate  
Labs 11–15: Prepare the Power Platform Environment; Build a Trigger and Actions Flow from Microsoft Forms; Log Form Submissions to Excel Online; Branch a Flow with a Condition; Suspend a Flow for a Human Approval

**Day 4 — Copilot Studio Agents** · Topic 04: Designing and Building Copilot Studio Agents  
Labs 16–20: Design a Scoped Agent Before You Build It; Build and Ground a Copilot Studio Agent; Give an Agent a Tool and a Knowledge Source; Orchestrate Connected Agents; Publish an Agent to Microsoft Teams

**Day 5 — Integration, Testing, Security and Assessment** · Topic 05: Integrating, Testing, Securing and Optimising Agentic Automation  
Labs 21–25: Expose a Flow over HTTP with a JSON Schema; Ground an Agent with Retrieval-Augmented Generation; Add a Human Review Gate to an Agent Action; Test, Secure and Troubleshoot the Solution; Operate a Governed End-to-End Copilot Pipeline
